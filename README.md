# CyberMath — GitHub Pages

Phiên bản web client-side của CyberMath: Hệ bất phương trình bậc nhất hai ẩn.

## Chạy cục bộ
Mở `index.html` trực tiếp bằng trình duyệt.

## GitHub Pages
Repository → Settings → Pages → Deploy from branch → `main` / `/ (root)` → Save.

Không cần Python, Flask, Render hay server backend.
